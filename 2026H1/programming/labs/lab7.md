## Задание 1 — Своя библиотека `finance.py` (встроенные библиотеки)

Создать файл `finance.py` и реализовать в нём следующие функции.

**1.1** — Функция `compound_interest(principal, rate, years)` — возвращает итоговую сумму при начислении сложного процента. Использовать `math`.

**1.2** — Функция `days_until(target_date_str)` — принимает строку в формате `"YYYY-MM-DD"`, возвращает количество дней от сегодня до указанной даты. Использовать `datetime`.

**1.3** — Функция `simulate_returns(days, min_pct, max_pct)` — возвращает список случайных дневных доходностей (в процентах) за указанное количество дней. Использовать `random`.

```python
# Ожидаемое поведение:
compound_interest(100_000, 0.10, 3)   # → 133100.0
days_until("2026-12-31")              # → количество дней до конца года
simulate_returns(5, -3.0, 3.0)        # → [-1.2, 2.3, 0.8, -0.5, 1.7]  (пример)
```
