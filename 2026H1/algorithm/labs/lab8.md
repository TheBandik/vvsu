## Задание №1 – Индекс поиска в сервисе рекомендаций

В backend-сервисе (например, рекомендательная система или каталог товаров) необходимо реализовать **быстрый поиск по числовым ключам** (ID, рейтинг, score).

В простейшей версии индекс хранится в виде **бинарного дерева поиска (BST)**.

---

### Требуется реализовать

Классы:

```python
class Node
class BST
```

Методы:

* `insert(key)`
* `search(key)`
* `inorder()`
* `preorder()`
* `postorder()`

---

### Сценарий

1. Сервис получает данные в виде потока:

```
[50, 30, 120, 70, 20, 90, 40, 60, 80]
```

2. На их основе строится индекс (BST)

3. Для отладки необходимо вывести:

* inorder (для проверки сортировки)
* preorder (для сериализации)
* postorder (для удаления/очистки)

---

### Дополнительный эксперимент

Сервис может получать данные:

* либо в случайном порядке
* либо уже отсортированные (например, после batch-обработки)

1. Построить второе дерево из:

```
[20, 30, 40, 50, 60, 70, 80, 90, 120]
```

2. Сравнить:

* высоту дерева
* количество сравнений при поиске элементов (например: 20, 80, 120)

---

### Формат вывода

```bash
Inorder: ...
Preorder: ...
Postorder: ...

Tree height: ...

Search comparisons:
20 -> X
80 -> X
120 -> X
```

## Задание №2 – Управление удалением в индексе

В том же сервисе необходимо реализовать **удаление элементов из индекса** (например, удаление товаров, пользователей, записей).

---

### Требуется реализовать

Методы:

* `delete(key)`
* `level_order()` – обход по уровням (BFS)

---

### Сценарий

Исходные данные:

```
[50, 30, 120, 70, 20, 90, 40, 60, 80]
```

---

### Шаги

1. Построить дерево
2. Вывести:

```bash
Initial:
Inorder: ...
Level-order: ...
```

3. Последовательно удалить:

```
20
30
50
```

После **каждого удаления** выводить:

```bash
After delete X:
Inorder: ...
Level-order: ...
```

---

### Важно

Необходимо явно обработать и прокомментировать три случая:

1. Удаление листа
2. Узел с одним потомком
3. Узел с двумя потомками

---

### Формат вывода

```bash
Initial:
Inorder: ...
Level-order: ...

After delete 20:
...

After delete 30:
...

After delete 50:
...
```
